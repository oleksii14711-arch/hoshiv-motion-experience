# REPORT — Гошів Motion Experience (Muse Spark 1.3)

Дата: 11.10.2026. Проєкт: `hoshiv-motion-spark-v1/`. Оригінал V30 збережено в `original-site/` без змін.

## Реалізовано

**Кінематографічний вступ 500vh (`CinematicIntro`)**
- `ScrollVideo` — HLS через hls.js (параметри зі специфікації: maxBufferLength 120, maxMaxBufferLength 600, maxBufferSize 200 МБ, вибір якості після MANIFEST_PARSED, обмеження якості на слабких пристроях, Safari — нативно). Факт: демо-HLS відтворюється (readyState 4, duration 6 с, без помилок декодера). Скраб обмежено секцією 500vh. Seek-контроль: currentTarget / seekPending / подія seeked / перевірка video.seeking. Паралакс курсора ±30px, 1.5 с, power2.out. Лоадер «Завантажуємо Гошів… %» з таймаутом 12 с. Під відео завжди працює scroll-driven фото-fallback зі справжніх панорам Гошева (кросфейд + наближення + затемнення).
- `ScrollFloat` — «ГОШІВ» (clamp 4rem/15vw/317px, line-height 0.85) + «МІЖ ГОРОЮ І КАРТОЮ»; 23 анімовані `.char`; кінцевий стан opacity 0 / yPercent 250 / scaleY 1.2 / scaleX 0.9; scrub 1.5, stagger 0.05, power2.inOut; reduced-motion — статичний заголовок.
- `GlassPanel` — геометрія 1250px / 900px / 85vh, перспектива 1000px; обчислений `backdrop-filter: blur(160px)` підтверджено в браузері (мобайл — 60px); виїзд знизу scrub 1.5; 3D-паралакс ±20px / ±4°; український контент + marquee «Ясна Гора · Гошів · 1779–1783 · 1861–1864 · 1912 · 1924 · Прикарпаття» (20 s, translateX −50%).
- `PillNav` — фіксоване меню, логотип 48px з 4-пелюстковим SVG і обертанням 360°; рідинний hover за формулою R/D/delta зі spec; два підписи; intro-анімації 0.6 с; навігація ScrollToPlugin 3 с power3.inOut до реальних якорів; мобільне меню <768px (гамбургер → X, popover, Escape, повернення фокусу).

**Змістовні розділи** — Святині (обидві обителі, фото не переплутані, галереї-перемикачі), Історія (5 історій + словник 1882 + бібліотека, усі посилальні URL збережено), Атлас (4 карти в одному вікні, tabs + стрілки + Home/End, zoom 100–300%, Escape, фокус), Громада (4 офіційні посилання), Бізнес (5 категорій без вигаданих контактів), Карта (OSM iframe + Ясна Гора 49.0258, 23.8802), Пісня (локальний mp3, тільки за натисканням — перевірено: грає/пауза), Footer з атрибуцією.

**Маршрут 1882** — in-app `/hoshiv-1882` (React) + статичний `hoshiv-1882.html` (повний оригінал) для прямого відкриття без 404. Обидва перевірені.

## Обмеження / не перевірено

- Демо-HLS — абстрактне відео зі специфікації (квітковий вагон), не Гошів; для продакшену замінити джерелом реальної зйомки (компонент готовий). Фото-fallback — справжній Гошів.
- Scroll-сценарії (scrub-анімації в русі) перевірені статично (тригери, параметри, початкові/кінцеві стани), але живий покадровий скрол у видимому вікні тут недоступний: у середовищі згасло видиме вікно браузера (screenshots перестали працювати), а у прихованій вкладці rAF тротлиться. Початкові стани (chars opacity 1, панель зсунута вниз) і прив'язки підтверджено.
- Мобільні ширини 360/390/768 перевірені лише кодом (адаптивний clamp, вертикальні tabs, гамбургер, зменшений blur); живий перегляд на цих ширинах не виконано.
- Lighthouse-аудит не запускався.
- Зовнішнє фото DSC_4324.jpg не входить до архіву — використано лише локальне sisters-front-2k.jpeg + посилання (права уточнити перед публікацією).
- Бандероль 1.03 МБ (gzip 333 КБ) — прийнятно для GSAP/HLS-сторінки; за потреби розбити на чанки.
